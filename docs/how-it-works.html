HOW TEXT FINDS IMAGES // QDRANT EDGE DEMO

No labels. No text-to-image generation. One shared vector space.
THE INTUITIVE (WRONG) MODEL

"We store images, label each one in English, then match the search text against the labels. Somewhere a text-to-image model translates between the two."

Nothing like this happens. The images are never labeled, and nothing is ever generated.

WHAT ACTUALLY HAPPENS

A CLIP-style dual encoder (SigLIP2) has two separate towers: one reads images, one reads text. Both output vectors in the same 768-dimensional space. They were trained on billions of image-caption pairs with one rule: a matching image and caption must land close together; a mismatched pair must land far apart. After training, the photo of a shopping cart and the words "a shopping cart" end up neighbors by construction.

The Shared Space

image vectors (stored in the Edge shard) text vector (computed per query, never stored)

Search is therefore a single operation: embed the query text, find the nearest image vectors by cosine similarity in the shard. The frames were never tagged, captioned, or classified when stored. Meaning lives in where the vector sits, not in any label.

One Primitive, Three Features

Memory Search

Your query goes through the text encoder; the shard returns the nearest stored frames.

text → k nearest images

Live Recognition (HUD)

15 phrases were embedded once at boot. Each new frame is compared against all of them; the top scorers are shown. Recomputed every frame, stored nowhere.

image → k nearest texts

Teach a Concept

Your phrase becomes one more text vector in the comparison set. ~10ms, no retraining. The model already "knows" the concept; you give it the words.

+1 text vector

This is the demo's deeper point: once everything is a vector in one space, perception, recognition, and recall are the same query against the same on-device engine.

Why Scores Look Low (and That's Normal)

below 0.08 · unrelated
0.08–0.10 · weak / guessing
0.10–0.20 · solid match

Text vectors and image vectors occupy slightly different regions of the space (the "modality gap"), so cross-modal cosine scores never approach 1.0. A 0.15 is a confident hit. Ranking is what matters, not the absolute number. The demo dims results and warns "weak match" when the best score falls below 0.09.

Honest Limits of the Current Model

LimitWhy
Small objects get missedFrames are seen at 224×224 in 16-pixel patches (siglip2-base). A small distant object is a few patches.
Composition is fuzzy"A man paying a vendor" tests relations between objects; contrastive training mostly learns what is present, not who does what to whom.
Phrasing mattersConcrete visual nouns ("striped awning") beat abstract phrases ("a place to buy lunch").
It can't see the futureMemory only contains what the robot has already seen. Chips unlock as the mission progresses for exactly this reason.

These are properties of the edge-sized encoder (SigLIP2-base, ~800MB for both towers), not of Qdrant Edge. The engine searches whatever vectors you give it; a stronger encoder drops in without changing a line of the search path.
